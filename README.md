# CodeAlpha_Chatbot

This is a simple rule-based chatbot made using Python as part of the CodeAlpha Python Programming Internship.



## About the Project

The chatbot can respond to some predefined messages entered by the user. It can handle basic greetings, simple questions and commands.

The conversation continues until the user enters "bye".



## Features

- Responds to greetings
- Answers basic questions
- Tells its name
- Explains what it can do
- Responds to "thank you"
- Responds to greetings based on the time of day
- Handles empty input
- Gives a message for unknown inputs
- Allows the user to exit the conversation



## Technologies Used

- Python



## Concepts Used

- Functions
- If-elif-else statements
- Lists
- Loops
- User input
- Strings
- Conditional statements



## How to Run

Make sure Python is installed on your computer.

Run the following command:

python chatbot.py



## Example

You: hello

Bot: Hello! How can I help you?

You: what is your name

Bot: I'm CodeBot, a simple rule-based chatbot built with Python.

You: bye

Bot: Goodbye! It was nice chatting with you.
